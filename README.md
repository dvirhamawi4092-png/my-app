# my-app

## מנקלה 🔴🔵

משחק מנקלה (חוקי Kalah) כאפליקציית ווב – HTML/CSS/JS בלבד, ללא תלויות.
פותחים את `mancala/index.html` בדפדפן (טלפון או מחשב).

- מול המחשב (קל / בינוני / קשה) או שני שחקנים על אותו מכשיר
- אבנים אדומות וכחולות מבריקות עם אנימציית פיזור
- פריסה אופקית במחשב ואנכית בטלפון במצב לאורך

## נגן שירים ותווים 🎸

`rush-player/` – מנגן שירים יחד עם התווים / הטאבים שלהם, הכול בדפדפן (הקבצים לא יוצאים מהמכשיר).

- **Guitar Pro / MusicXML** (`.gp`, `.gp3`–`.gp5`, `.gpx`, `.musicxml`, `.mxl`): התווים מוצגים עם סמן שזז יחד עם ההקלטה המקורית, או מתנגנים בסינתיסייזר. אפשר לבחור כלי (גיטרה / בס / תופים), להפעיל מטרונום ולכוון את ה"סנכרון" (כמה שניות לפני התו הראשון).
- **PDF / תמונות**: דפי התווים נגללים לבד לפי מיקום השיר.
- האטה (50%–125%) בלי שינוי גובה הצליל, לופ A‑B, חיפוש, מקש רווח = נגן/השהה.
- קבצים עם אותו שם מתחברים לשיר אחד, למשל `01 - Rush - Tom Sawyer.mp3` + `Tom Sawyer (tab).gp5`.

הפעלה: צריך שרת (לא `file://`), למשל `cd rush-player && python3 -m http.server` ואז http://localhost:8000, או דרך GitHub Pages.
ספריות כלולות בתיקייה `vendor/`: [alphaTab](https://alphatab.net) (MPL‑2.0) ו‑[pdf.js](https://mozilla.github.io/pdf.js/) (Apache‑2.0).
